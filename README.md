# Payslip Generator

เว็บสร้างสลิปเงินเดือนภาษาไทยจากไฟล์ Excel / CSV ทำงานในเบราว์เซอร์ทั้งหมด **ข้อมูลพนักงานไม่ถูกส่งไปที่เซิร์ฟเวอร์**

อัปโหลดรายชื่อพนักงาน แล้วได้สลิป PDF รายงานภาษี ไฟล์โอนเงินธนาคาร และไฟล์ประกันสังคม ในที่เดียว

## ความสามารถ

- **อัปโหลดไฟล์** `.xlsx` `.xls` `.csv` (ไม่เกิน 25 MB) รองรับหัวคอลัมน์ภาษาไทยและอังกฤษ และเดาการจับคู่คอลัมน์ให้อัตโนมัติ
- **ตรวจข้อมูล** รหัสซ้ำ เลขบัตรประชาชน 13 หลัก (ตรวจหลักสุดท้าย) เลขบัญชี ตัวเลขติดลบหรือไม่ใช่ตัวเลข แล้วทำเครื่องหมายแถวที่มีปัญหา
- **แก้ข้อมูลในตารางได้เลย** คลิกที่ช่อง แก้แล้วระบบตรวจและคำนวณใหม่ทันที (ไม่แก้ไฟล์ต้นฉบับ)
- **คำนวณ** ประกันสังคม และภาษีหัก ณ ที่จ่าย ปรับสูตรได้ (อัตรา ฐานค่าจ้าง เพดาน โหมดภาษี ค่าใช้จ่าย)
- **สลิปเงินเดือน PDF** เลือกขนาดกระดาษได้ ใส่ชื่อบริษัท ที่อยู่ และลายเซ็น (ลบพื้นหลังรูปลายเซ็นให้อัตโนมัติ) ออกเป็นไฟล์ ZIP
- **รายงานภาษี** ภ.ง.ด.1, ภ.ง.ด.1ก และ หนังสือรับรองการหักภาษี ณ ที่จ่าย (50 ทวิ)
- **ไฟล์โอนเงิน** KBANK, SCB, BBL, TTB
- **ไฟล์ประกันสังคม** (ESSO) ความกว้างคงที่ เข้ารหัส TIS-620
- **ที่อยู่** เลือก จังหวัด → อำเภอ → ตำบล จากลิสต์ แล้วต่อลงในช่องที่อยู่
- **ดูตัวอย่าง** ดูสลิปและเอกสารทุกประเภทแบบเต็มจอ เลื่อนดูได้ทีละแผ่น ขยายดูรายละเอียดได้

## เริ่มใช้งาน

ต้องมี [Node.js](https://nodejs.org) 20.19 ขึ้นไป (ตามที่ Vite 8 ต้องการ)

```bash
npm install
npm run dev      # เปิดหน้าเว็บสำหรับพัฒนา
npm run build    # ตรวจชนิดข้อมูลและสร้างไฟล์สำหรับใช้งานจริง (โฟลเดอร์ dist)
npm run preview  # ลองเปิดไฟล์ที่ build แล้ว
npm test         # รันชุดทดสอบ
```

มีไฟล์ตัวอย่างให้ลองในโฟลเดอร์ `sample-data/` เช่น `employees.xlsx`, `employees.csv`, `employees-thai-headers.xlsx` และ `employees-with-errors.csv` (ใช้ทดสอบหน้าตรวจข้อผิดพลาด) ข้อมูลทั้งหมดเป็นข้อมูลจำลอง

## ขั้นตอนในหน้าเว็บ

1. อัปโหลดไฟล์
2. จับคู่คอลัมน์
3. ตรวจสอบและแก้ไขข้อมูล
4. ข้อมูลบริษัท งวดเงินเดือน ขนาดกระดาษ และสูตรคำนวณ
5. สร้างเอกสาร (ดาวน์โหลดหรือดูตัวอย่างก่อน)

## โครงสร้างโปรเจกต์

```
src/
  App.tsx          หน้าหลักและขั้นตอนทั้ง 5
  Viewer.tsx       หน้าดูตัวอย่างเอกสารแบบเต็มจอ
  Select.tsx       ลิสต์เลือกแบบกำหนดเอง
  Picker.tsx       ตัวเลือกวันที่ (ปี พ.ศ.)
  theme.css        สไตล์หลักของหน้าตาแบบกระจก
  lib/
    parse.ts       อ่านไฟล์ Excel / CSV
    mapping.ts     เดาการจับคู่คอลัมน์
    validate.ts    ตรวจข้อมูลและสร้างรายการพนักงาน
    calc.ts        คำนวณประกันสังคม ภาษี และเงินสุทธิ
    slip.ts        วาดสลิปและลายเซ็น
    taxReports.ts  รายงานภาษี
    bankEsso.ts    ไฟล์โอนเงินและไฟล์ประกันสังคม
    generate.ts    รวมไฟล์เป็น PDF / ZIP
  data/            รายชื่อจังหวัด อำเภอ ตำบล
```

เทคโนโลยี: Vite, React, TypeScript, jsPDF, JSZip, SheetJS (xlsx), vitest

## สิ่งที่ควรรู้ก่อนใช้งานจริง

- **รูปแบบไฟล์โอนเงินและไฟล์ประกันสังคมเป็นรูปแบบทั่วไป** ยังไม่ได้ตรวจกับแม่แบบทางการของแต่ละธนาคารและ สปส. ควรเทียบกับแม่แบบจริงก่อนส่ง
- **รายงานภาษีเป็นหน้าสรุปที่ออกแบบเอง** ไม่ใช่แบบฟอร์มทางการของกรมสรรพากร
- สูตรประกันสังคมและภาษีเป็นค่าตั้งต้นที่ปรับได้ ผู้ใช้ต้องตรวจสอบความถูกต้องกับกฎหมายและนโยบายของบริษัทเอง
- การแก้ไขในตารางอยู่ในหน้าเว็บเท่านั้น หากอัปโหลดไฟล์ใหม่ ค่าที่แก้จะหายไป
- การตั้งรหัสผ่านไฟล์ PDF ปิดไว้ (โค้ดยังอยู่ใน `src/lib/slip.ts` แบบคอมเมนต์)

## ความเป็นส่วนตัว

ไฟล์ที่อัปโหลดถูกอ่านและประมวลผลในเบราว์เซอร์ของผู้ใช้เท่านั้น ไม่มีการส่งข้อมูลไปยังเซิร์ฟเวอร์ภายนอก
